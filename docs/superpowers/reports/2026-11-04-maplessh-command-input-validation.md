# 多行命令框与可备份快捷按钮

日期：2026-11-04。

## 实现范围

- 每个 SSH 标签页拥有独立多行命令输入框，普通 Enter 仅换行，执行按钮或框内 Ctrl+Enter 发送全部内容。手动多行执行前确认对应主机名称、地址、端口及行数；发送后保留草稿，清空按钮可移除。草稿不持久化、不进入备份。
- 规范化 CRLF、LF、CR 为交互终端回车，末行缺少回车时自动补齐，保留缩进、空行及 UTF-8。拒绝空白命令、不支持的控制字符和规范化后超过 1 MiB 的内容。
- 命令框上方添加命名快捷按钮，默认带入当前命令框内容。点击按钮直接发送到对应会话，不弹出二次执行确认；右键编辑、删除。多个按钮通过水平滚动容纳，快捷目录在所有会话共享，不广播命令。
- 未连接或断开时拒绝发送，SSH Send 返回实际是否接受到输入队列；不会将断线输入留待重连执行。成功提示仅表示提交发送，远程结果仍须看终端；前台若为其他交互程序，命令同样由该程序接收。
- 配置和备份格式升级为版本 3，新增 quick_commands，每条包含 id、name、command。严格校验字段、唯一标识、名称、内容及最多 200 条限制。会话、共享凭据、快捷命令一起手动备份和恢复，不含本机指纹、WebDAV 设置、草稿、日志或输出。
- 兼容版本 1、2 明文配置及备份，旧格式快捷命令为空。版本 2 首次保存前保留 vault.before-quick-commands.*.json 原字节副本，版本 1 保留既有 vault.before-credentials.*.json 迁移副本。恢复前预览快捷命令数量，保留原配置恢复副本；打开的连接和草稿不自动执行。
- 会话标签改为容器面板，终端、命令框和快捷区保持在同一页面；选择、重连、标题更新及关闭均以页面识别对应会话。
