# 共享凭据、分组改名与中文绘制验证

日期：2026-11-03。

## 实现范围

- 凭据独立命名和管理，主机会话通过 credential_id 引用；新增、编辑主机时可选择已有凭据。密码和私钥认证均可复用。
- 凭据管理支持新增、编辑、删除；仍被主机使用的凭据禁止删除。共享凭据修改在下一次连接或重连生效，已打开连接保留自己的快照。
- 会话编辑窗口内的凭据修改属于同一草稿，取消会话编辑一并放弃。
- 分组支持右键“重命名分组…”，同组主机统一更新，拒绝空白名称和已有其他分组名称。
- 修复 libvterm 中文宽字符续格绘制：续格的 chars[0] 为 UINT32_MAX，而 width 可能为 1；绘制时直接跳过该续格，避免覆盖汉字后半部分。
- 配置和备份升级为版本 2，独立保存会话与凭据目录。可读取版本 1 明文格式并提取、去重认证资料；首次保存旧配置前保留完整原文件 vault.before-credentials.*.json。
- 手动备份保留完整凭据目录与共享引用关系，不包含本机指纹或 WebDAV 设置。恢复前校验引用完整性。
