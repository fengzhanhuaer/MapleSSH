# 可调命令区、侧栏收纳与深色输入框

日期：2026-11-04。

## 实现

- 命令框删除占位提示，Enter 或 Ctrl+Enter 直接发送全部内容，Shift+Enter 写入标准换行，保留多行粘贴及执行按钮。
- 命令输入框背景 RGB(17,22,31)，文字 RGB(221,228,238)，与终端正常配色一致。
- 每个会话在终端与命令区之间使用横向 wxSplitterWindow，支持上下拖动实时调整。命令框随命令区伸缩，保留快捷按钮和操作按钮所需的最小高度；分隔线重力设为 1，使窗口尺寸变化时优先改变终端高度。
- 工具栏新增“会话栏”切换按钮，视图菜单提供同名勾选项及 Ctrl+Shift+L 快捷键。收起时仅隐藏树控件，终端占用剩余宽度，展开时恢复本次收起前的宽度；菜单和按钮状态同步。
- 隐藏/调整布局不销毁终端或命令草稿、不主动断开连接。命令区高度按标签独立，侧栏宽度在本次运行期间保留，均不跨重启保存。
