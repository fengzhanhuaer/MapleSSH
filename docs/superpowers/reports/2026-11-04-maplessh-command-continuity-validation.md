# 命令区连续配色与回车清空

日期：2026-11-04。

## 修改

- 删除“命令输入”标题，快捷行由 42 DIP 缩为 34 DIP，去除快捷行上留白，将输入区边距由 8 DIP 减为 4 DIP，默认命令区高度由 190 DIP 减为 150 DIP；仍可拖动调整。
- 命令区面板、快捷滚动区域和输入框统一使用终端深色背景；移除输入框边框，保留浅色文字。分隔器仅重绘深色底和一条弱对比细线，不改变原有分隔条命中范围或拖动逻辑。
- Enter、小键盘 Enter 和 Ctrl+Enter 成功提交发送队列后清空输入框，并保留输入焦点；连接不可用、内容校验或队列提交失败时保留原文。Shift+Enter 仍插入换行，按钮执行仍保留原文，快捷按钮不清空草稿。
- 清空以 SSH Send 成功提交为依据，不等同于服务器收到或执行成功，不自动重发。
