# 终端间距与分组下拉选择

日期：2026-11-03。

## 修改

- 连接状态提示原来同时在开头和末尾换行，导致连续提示间多出空行。现在仅在光标不在行首时先换行，每条提示保留一个结束换行，避免接在远程提示符后。
- 终端行高使用字体测量高度，移除原来额外增加的 2 像素。绘制、选择、光标、终端行数及 PTY 尺寸继续共享同一行高。
- 服务器输出仍原样送入 libvterm，保留原本的空行和控制序列。
- 新建、编辑会话中的分组改为可编辑下拉框，列出当前配置中去重、排序后的已有非空分组；保留当前分组值，允许输入新名称或清空为未分组。
- 按用户要求移除备份确认框中的指定说明句。
