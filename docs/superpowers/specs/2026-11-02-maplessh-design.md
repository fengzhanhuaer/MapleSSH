# MapleSSH Windows 首版设计

日期：2026-11-02。状态：用户已确认方向并授权实施；首版实现与验证范围见 ../reports/2026-11-02-maplessh-validation.md，不等同于完整人工验收。

## 已确认需求

- SSH 桌面工具 MapleSSH，使用 wxWidgets 原生界面，首版仅 Windows x64。
- 单文件绿色部署，交付 MapleSSH.exe；允许运行后在程序同目录生成用户数据。
- IP 或域名、用户名、密码、私钥等 SSH 资料，通过已部署的 MapleStore WebDAV 备份。
- 手动备份、手动恢复，不自动上传，不做多端实时同步。
- 主机指纹不备份，只保存在本机；换电脑首次连接重新确认。
- 不修改 MapleStore 的既有代码、发布及部署，不增加专用服务端接口。

## 首版默认范围

以下为建议默认方案，不等同于用户逐项指定：

- 中文界面：左侧会话分组与连接列表，右侧多标签终端。
- 新增、编辑、删除会话，保存名称、分组、地址、端口、用户名、认证方式和连接超时。
- 密码登录、私钥登录、加密私钥口令；保存导入私钥实际内容，而非本机路径。
- 交互式 PTY、UTF-8 中文、ANSI 颜色、滚屏、复制粘贴、字体缩放和终端尺寸更新。
- 连接、断开、手动重连，不自动重放命令。
- 主密码解锁本地敏感资料及加密备份；主密码不落盘、不上传，遗失后不能恢复凭据。
- WebDAV 设置、手动备份、备份列表及手动恢复。
- SFTP、端口转发、跳板机、SSH Agent、串口及自动脚本暂不纳入首版。

## 技术路线与模块

比较三条路线：内嵌原生库、调用命令行客户端、内嵌网页终端。选择原生库路线，避免依赖系统 SSH、释放辅助程序或增加浏览器运行时前提；代价是需要接入终端绘制和后台连接生命周期。

建议采用 C++20、CMake、wxWidgets、libssh2、libvterm、OpenSSL；WebDAV 使用 Windows WinHTTP。固定依赖源码版本或提交并校验下载内容，不以浮动分支发布。具体版本以 Windows 静态构建验证为准。

桌面工程位于 MapleSSH/，与 MapleStore/ 分离。

| 模块 | 职责 |
| --- | --- |
| app、ui | 启动解锁、主窗口、会话编辑、标签和确认对话框 |
| sessions | 会话模型、分组、稳定标识及校验，不依赖 UI |
| ssh | TCP、握手、主机检查、认证、PTY、状态和取消 |
| terminal | libvterm 封装、输入转换、屏幕、滚屏及绘制 |
| storage | 版本、加密封装、原子存储及恢复前副本 |
| backup | 字段白名单、WebDAV、列表、验证及恢复 |

每条 SSH 连接由专属工作线程独占资源，通过消息与 UI 通信；终端状态和控件只在 UI 线程更新。网络和密码派生不能阻塞界面。关闭标签或窗口必须取消工作并回收线程，晚到事件不能访问销毁控件。

## 单文件与本地存储

- 第三方库和 C/C++ 运行库静态链接，只依赖 Windows 自带系统 DLL。
- 不要求用户安装 VC 运行库、OpenSSH、WebView、Python 或 Node；区分构建依赖与运行依赖。
- 图标、清单、许可证和第三方声明内嵌，不释放辅助 EXE、DLL 或明文私钥。
- 数据路径相对 EXE，而非工作目录；不写注册表、不自动切换 AppData、不要求管理员权限。
- config/vault.msv 保存加密会话、私钥及 WebDAV 设置；config/known_hosts 独立保存本机主机密钥。首版暂不持久化字体和窗口布局，因此不生成 settings.json；以后若增加此文件，仅保存非敏感界面设置。
- 程序目录不可写时明确提示；同一配置只允许一个可写实例。写临时文件并刷盘后原子替换，失败保留旧配置。
- 日志不包含密码、私钥、主密码、认证报文、Authorization 头或终端正文。

建议使用版本化加密封装，包含格式版本、随机盐、随机 nonce、密文长度、密文及认证标签；头部也参与认证。通过 OpenSSL scrypt 派生密钥，使用 AES-256-GCM，不自行实现密码算法。

版本 1 建议固定 scrypt 参数 N=131072、r=8、p=1，内存上限 256 MiB；盐 16 字节、nonce 12 字节、密钥 32 字节、标签 16 字节。每次加密重新生成盐和 nonce。读取端只接受已实现格式及固定参数，不能由不可信文件指定任意计算开销。

配置和下载体上限 32 MiB，单个私钥上限 1 MiB，会话最多 1000 条；超限拒绝，不截断。私钥格式逐项测试，不承诺支持所有 PuTTY、证书或硬件令牌格式。

## 本机主机信任

按地址及端口区分主机。首次展示算法和 SHA-256 指纹，由用户确认后本机保存。已知主机密钥变化时阻止认证，不自动覆盖；修改信任记录需独立确认。确认身份前不发送密码、不执行客户端私钥认证。

不备份指纹不等于关闭身份验证。恢复不删除、不覆盖本机 known_hosts，新电脑连接恢复出的会话时重新确认。

## 手动 WebDAV 备份恢复

复用 MapleStore /dav/ 和账号 Basic 认证，不使用网页 Cookie 或管理 API；仅操作该账号自己的目录。

字段白名单包括会话标识、名称、分组、地址、端口、用户名、认证方式、SSH 密码、私钥内容、私钥口令及连接选项。不得整体打包 config/，不含指纹、日志、终端历史或其他文件。

WebDAV 地址、账号和密码仅作为本机通道设置，不写入其自身备份；新电脑先填写 WebDAV 信息，再输入主密码恢复。

备份：用户点击并确认目标后建立快照，在本地加密，上传到配置的 MapleSSH 子目录。文件名使用 UTC 时间加随机标识，不含主机地址或用户名。先 PUT 至随机加密临时文件，再 MOVE / Overwrite: F 发布为最终备份名；回读核对长度及摘要后才显示成功。不自动删除旧备份、不后台补传。联调证实 Go WebDAV 的 PUT 不处理 If-None-Match，因此禁止覆盖由 MOVE 语义保证。取消可能留下加密临时文件，可手动清理。

恢复：PROPFIND Depth: 1 列出直接子文件，GET 下载所选备份；限制大小，检查版本、认证标签、字段及会话标识唯一性。XML 禁用外部实体，拒绝跨源或越界路径。完整解密验证后预览数量，用户确认再保存当前加密配置副本并原子替换会话列表。首版不自动合并。

恢复保留当前 WebDAV 设置、本机 known_hosts 和正在运行的连接，不自动连接或执行命令。错误密码、损坏数据、写盘失败或取消均不改变当前配置。

WebDAV 默认 HTTPS 并验证证书；仅 localhost、127.0.0.1、::1 可用 HTTP 本机调试，远程私网及 VPN 地址仍使用 HTTPS。不提供忽略证书错误开关，不跨源携带认证头或自动跟随跨源重定向。所有网络任务有超时和取消。

## 实现与验收顺序

1. 静态依赖、CMake、最小 wxWidgets 窗口及 x64 Release，检查额外 DLL 依赖。
2. 会话模型、加密封装、原子存储、备份白名单及独立主机信任记录。
3. 会话编辑、多标签及终端绘制，离线测试中文、颜色、光标和屏幕更新。
4. SSH 登录、PTY、首次信任、密钥变化、断线、超时、取消及标签生命周期。
5. 手动 WebDAV 备份恢复，使用隔离账号及目录联调，不操作现有用户文件。
6. 未安装开发环境的 Windows 单文件运行、目录迁移、中文路径和不可写目录验证；实际检查 vim/top 和长输出。

测试至少覆盖加解密往返、随机盐和 nonce、错误密码、篡改、截断、超限、重复会话标识、备份不含指纹及 WebDAV 凭据、失败不覆盖配置、401/403、超时、取消及上传回读失败。

本地编译、单元测试、SSH 集成、WebDAV 联调、桌面操作和无开发环境验证分开报告；未执行项目明确标注，不把单项通过称为全部完成。
