# MapleSSH 文件浏览与传输

## 范围

保持 Windows x64、wxWidgets、libssh2、单 EXE 绿色部署。每个会话增加右侧可调宽、可收起的文件浏览器，提供路径栏、上一级、刷新、上传、下载、取消和明确的 cd 跳转。根据用户后续要求，非根目录显示 .. 父目录项，支持右键上传下载和 cd；cd 直接发送，不弹确认窗口。切换标签保留各自目录；浏览不自动发送命令。第一版传输单个普通文件，不递归处理目录。

## 传输与安全

SFTP 是文件浏览和传输协议，不依赖外部 scp.exe。使用与终端相同的已保存会话及连接时的凭据快照，但单独建立后台连接，主机公钥必须与当前已认证终端完全相同，并在发送凭据前检查；终端不在线不得提交新文件任务。不得自动信任新主机。断开/重连/关闭会话取消文件任务。

所有网络及文件传输在后台执行，任务具有进度、取消、超时和有界结果。上传到随机临时文件，完成并确认关闭后重命名到目标；下载到同目录随机临时文件，完成后发布。默认拒绝覆盖，覆盖必须明确确认。失败不替换旧文件，不把部分下载当成功；临时文件尽力删除。路径、Unicode、引号、空格和 shell 元字符须测试；cd 仅支持 POSIX shell 并明确提示，不从服务器输出拼接执行命令。

## UI 与 MCP

右侧浏览器用独立组件封装，跟随会话、可收起、恢复本次宽度，背景保持深色。状态和错误在面板内显示。MCP 增加 list_directory、upload_file、download_file、get_file_job、cancel_file_job；文件工具返回异步任务 ID，上传/下载本地路径需要界面批准，结果查询不阻塞 GUI。目录列表仅有名称、类型、大小等元信息，不包含凭据。MCP 文件工具不能绕过断开状态、覆盖保护及本地文件访问批准。

## 验证

先做路径/cd/任务与协议回归测试，再用隔离回环 SSH/SFTP fixture 验证列目录、二进制/中文文件往返、拒绝覆盖、取消、认证前主机校验、断开清理。后台完成 Release、CTest 和 PE 依赖检查；不操作用户界面、真实服务器或真实凭据。桌面交互人工验收单独说明。
