# MapleSSH Implementation Plan

Date: 2026-11-02. Initial implementation built and locally validated. Manual acceptance remains open as listed below.

Goal: Windows x64 portable wxWidgets SSH client, passwordless local JSON sessions and manual JSON WebDAV backups excluding host trust records. User requested removal of the application master password after the initial build.
Spec: docs/superpowers/specs/2026-11-02-maplessh-design.md
Evidence: docs/superpowers/reports/2026-11-02-maplessh-validation.md

## Constraints and decisions

- Work locally; no delegated agents, branches, commits, remote deployment or production credentials.
- Preserve MapleStore source and deployments. Use isolated loopback services for verification.
- Static wxWidgets, libssh2, OpenSSL and libvterm plus /MT; fixed source archive versions with SHA-256 verification.
- Use source archives rather than vcpkg. Preparation and build scripts replace the originally proposed manifest, triplet and presets.
- No automatic synchronization, SFTP, forwarding, jump hosts, scripts or password recovery in this version.
