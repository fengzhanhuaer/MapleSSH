# MapleStore 最小设计

## 已确认需求

- 独立 Go 子工程，通过一个 Docker 容器部署到个人 NAS。
- 提供 WebDAV 和内置轻量中文文件管理页面。
- 多账号，每个账号只有自己的独立目录，不提供跨账号共享。
- 上传、下载、列目录、建目录、复制、移动、重命名、删除；删除不进入回收站。
- compose.yaml 默认将同级 ./data 挂载为 /data，账号目录为 ./data/<账号名>/。
- 账号及密码哈希单独保存在同级 ./config，不允许通过文件接口访问。
- 管理员可以建号、停用、重置密码、设置只读；管理员的文件入口也仅访问自己的目录。
- 不使用数据库，不做自动同步、历史版本、去重和复杂后台。

## 实现约束

- Go 1.26，标准库 HTTP 服务，复用 golang.org/x/net/webdav，前端为内嵌静态页面。
- 每次请求检查账号状态和权限；使用 os.Root 约束账号文件操作。
- Argon2id 保存密码，随机 Cookie 会话、CSRF 校验、登录限速和有界认证并发。
- 上传采用同目录临时文件，失败时不得覆盖旧内容；拒绝操作账号根目录。
- 管理员账号密码必须通过 Compose 环境变量传入，不提供默认密码；修改密码重启生效，网页不得修改管理员凭据。
- 默认 Compose 端口仅绑定 NAS 回环地址；远程使用 HTTPS 反向代理或 VPN。
- 正式镜像由 GitHub Actions 构建为 linux/amd64、linux/arm64 并发布到 GHCR；默认 Compose 仅拉取镜像，本地构建使用单独覆盖文件。
- NAS 管理员、宿主机 root、磁盘访问者不在账号隔离防护边界内。

## 验收

测试覆盖账号持久化、密码验证、跨账号隔离、路径及符号链接越界、读写权限、账号停用和密码重置后会话失效、CSRF、失败上传保留旧文件，以及完整 WebDAV 操作。
执行 Go 测试、vet、Linux amd64/arm64 编译；环境有 Docker 时再执行实际镜像验证，不将交叉编译称为容器部署。
